## English

This repository contains my personal journey from **Python fundamentals** to **algorithm implementation**. It's designed for those who are new to Python or preparing for coding interviews.

### 📂 **Repository Structure**

* `01_python_basics/`: Core Python syntax and concepts.
    * `data_types.ipynb`: Data types (string, list, tuple, dictionary)
    * `control_flow.ipynb`: Control flow (conditional statements, loops)
    * `functions.ipynb`: Functions and lambda expressions
    * `classes.ipynb`: Classes and object-oriented programming
* `02_algorithms/`: Code for various algorithms and data structures.
    * `search_algorithms/`: Search algorithms (binary search, DFS, BFS)
    * `sort_algorithms/`: Sorting algorithms (insertion sort, merge sort, quick sort)
    * `data_structures/`: Data structures (stack, queue, linked list)
    * `dynamic_programming/`: Dynamic programming solutions

### **Getting Started**

Launch Jupyter Notebook to view the `.ipynb` files.
    ```bash
    jupyter notebook
    ```

### **Contributing**

Feel free to open a pull request! Any feedback, suggestions for new problems, or code improvements are welcome.

## 한국어

이 저장소는 **파이썬 기초 문법**부터 **알고리즘 구현**까지의 과정을 담고 있습니다. 파이썬을 처음 배우거나 코딩 테스트를 준비하는 분들을 위한 학습 및 복습용 자료로 활용될 수 있습니다.

### 📂 **폴더**

* `01_python_basics/`: 파이썬의 핵심 문법과 기본 개념
    * `data_types.ipynb`: 자료형 (문자열, 리스트, 튜플, 딕셔너리)
    * `control_flow.ipynb`: 제어문 (조건문, 반복문)
    * `functions.ipynb`: 함수와 람다 표현식
    * `classes.ipynb`: 클래스와 객체 지향 프로그래밍
* `02_algorithms/`: 주요 알고리즘 및 자료구조 구현 코드
    * `search_algorithms/`: 탐색 알고리즘 (이진 탐색, DFS, BFS)
    * `sort_algorithms/`: 정렬 알고리즘 (삽입 정렬, 병합 정렬, 퀵 정렬)
    * `data_structures/`: 자료구조 (스택, 큐, 링크드 리스트)
    * `dynamic_programming/`: 동적 계획법 문제 풀이

### **시작**

Jupyter Notebook을 실행하여 `.ipynb` 파일을 열어보세요.
    ```bash
    jupyter notebook
    ```
